# Edit a layout during quote review

Continues website draft 9b0008885e1584269a9b6c0c6e06faa02f503bb6. Adds Edit this layout to valid incoming quote concepts. The dialog edits geometry on the current quote page; contact fields, customer notes and design-studio entries remain in their original DOM. No contact data is placed in links or browser storage, and editing does not submit an inquiry.

The dialog uses the public planner's existing validation and 2D/projected SVG functions. Supports all three shapes, quarter-inch dimensions, and up to four reserved spaces. Invalid geometry, overlapping spaces, absent walls and out-of-run widths disable Apply and clear the draft drawings. Cancel and Escape discard draft changes and return focus to the edit button. Reopening starts from the last applied concept.

Apply replaces only the normalized layout, refreshes the summary, updates the existing page URL's layout parameter, and clears the layout-inclusion checkbox for renewed customer review. Quote service selection is retained; the existing Custom Cabinetry mismatch guard still applies. Older v1 concepts remain v1 unless spaces are added. Pending submissions close/lock the editor; confirmed submissions keep it locked, while failed submissions restore editing. Detached apply controls cannot change the pending/confirmed payload. No schema, backend, pricing or production-release changes.
