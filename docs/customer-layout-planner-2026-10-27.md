# Customer cabinet layout planner

Continues website preview eae17d5f6387bd5e918d6241697eada742565c17. Preview only; website production remains unchanged. JARVIS development remains 173 and production remains 164.

Adds kitchen-planner.html, linked from the home design studio and cabinetry service page. Customers can enter room width/depth, cabinet depth/height and a nominal module width, then choose straight, L-shaped or U-shaped base-cabinet runs. Values are inches in quarter-inch increments with explicit bounds; they are validated without rounding or silent clamping.

The public pure geometry module creates rectangular cabinet volumes, a dimensioned SVG top view and an SVG projection of actual 3D vertices. The view-angle slider rotates the projection. Modules stay inside the room and do not overlap; return runs start after the back run's depth. Remaining run space is displayed as unallocated and is not silently filled. U-shaped concepts also display their open width, expressly without claiming a verified working clearance. No private JARVIS cabinet, drawer, machining or cut-list code was copied into the public repository.

This is an early customer planning tool. It does not model appliances, doors/windows, utilities, upper cabinets, countertop overhangs, accessibility or corner-access solutions. Cabinet feasibility, exact dimensions, layout clearances and pricing require contractor review. The schematic does not generate a fabrication plan, a price or a photorealistic render.
